# 泰山行记 · 微信 H5

点击“启程登山”，封面开始播放东岳泰山的童声介绍，讲完后镜头自动移向天外村。关闭讲解时直接进山。沿途依次游览天外村、中天门、南天门、天街、碧霞祠、大观峰、玉皇顶。到站后，实景小窗展示照片和游记短文，同时播放本站讲解。顶部可分别开关讲解与配乐。

末站讲解结束或点击“登顶远眺”后，镜头随鼓点拉远。群山全景停稳，杜甫《望岳》的“会当凌绝顶，一览众山小”以书法题字浮现，随后显示登顶印章与游览足迹。

## 本地开发

需要 Node.js 20.19+ 或 22.12+。在项目目录执行：

```sh
npm install
npm run dev
```

浏览器打开终端显示的地址。`src/stops.ts` 保存景点和路线信息，`src/scrollWorld.ts` 绘制连续山水并控制镜头，`src/audioCatalog.ts` 对应语音与讲解词，`src/photoCredits.ts` 记录摄影来源与许可。照片、音频和标题字体随页面一同发布。

## 发布到 GitHub Pages

工作区已包含 `.github/workflows/deploy-pages.yml`。把整个项目推送到 GitHub 仓库的 `main` 分支后，GitHub Actions 会自动构建并发布 `dist/`。第一次发布前，在仓库的 **Settings → Pages → Build and deployment** 中将 **Source** 选为 **GitHub Actions**。随后在 **Actions** 页面查看部署是否成功，网址会显示为 `https://<用户名>.github.io/<仓库名>/`。

Pages 使用项目自带的 GitHub Actions 权限，不需要个人访问令牌或单独配置密钥。

## 其他静态托管服务

```sh
npm run build
```

将生成的 `dist/` 目录发布到支持 HTTPS 的静态托管服务，得到的公网 URL 就可以在微信中打开。项目使用相对资源路径，可发布在域名根目录或子目录。发布后请用微信内置浏览器打开实际链接检查页面和图片是否正常加载。

如果使用中国内地服务器或域名，可能需要按托管商要求完成 ICP 备案。自定义微信分享卡片、微信网页授权、微信支付等功能需要在明确需求后另行配置相应的微信平台权限、域名及服务端接口；目前的普通网页不依赖这些功能。
